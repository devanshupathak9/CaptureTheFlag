# 🗂️ Write-up Index

Challenges are grouped by **source** (the platform or event they came from), then by
**category**, then by challenge.

* **Platforms** — always-on practice sites, no year in the folder name (`hack-the-box`, `adworld`).
* **Events** — time-boxed competitions, year in the folder name (`patriot-ctf-2025`).

Category folder names are kept short and consistent across every source:
`web`, `pwn`, `rev`, `crypto`, `forensics`, `osint`, `misc`.
