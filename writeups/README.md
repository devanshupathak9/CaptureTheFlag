# 🗂️ Write-up Index

Challenges are grouped by **source** (the platform or event they came from). Each
challenge folder is named `<category>_<challenge>`, so the category is visible
right in the listing without opening the folder.

* **Platforms** — always-on practice sites, no year in the folder name (`hack-the-box`, `adworld`).
* **Events** — time-boxed competitions, year in the folder name (`patriot-ctf-2025`).

Category prefixes: `web`, `pwn`, `rev`, `crypto`, `forensics`, `osint`, `misc`.
